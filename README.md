# 🏰 Vocabulary Castle League · 학교대항 어휘성 공략전

> «혼자서는 단어를 볼 수 있지만, 함께해야 성을 열 수 있다.»
> **Share the clue. Build the word. Open the castle.**

4인 팀이 **서로 다른 단서**를 하나씩 나눠 갖고, 말로 공유·조합해 어휘성을 공략하는
**협력형 정보차(Information-Gap) 어휘 학습 게임**입니다. 단순히 개인이 문제를 많이
맞히는 경쟁이 아니라, 언어학습의 **Communicative Activity / Information-Gap** 원리를
게임으로 구현했습니다.

- **키워드:** #어휘학습게임 #학교대항전 #InformationGap #CommunicativeActivity #협력학습 #수능어휘
- **대상:** 초·중·고 영어 학습자 (교실·동아리·학교대항전)

## 🎮 바로 플레이

이 저장소는 **단일 HTML 파일**(`index.html`) 하나로 동작합니다. 빌드·설치·서버가 필요 없어요.

- **로컬:** `index.html` 을 브라우저로 열면 끝.
- **GitHub Pages:** 저장소 **Settings → Pages → Branch: `main` / `/root`** 로 설정하면
  `https://smilepat.github.io/vocabulary-castle-league/` 에서 바로 플레이됩니다.

기록(순위표)은 **이 기기(브라우저)의 localStorage** 에만 저장되며, 외부 서버로 전송되지 않습니다.

## ✅ 문항을 고치기 전에 — 검증

`data/words.js` 만 편집하면 문항이 바뀌는 구조라, **잘못 편집했을 때 게임을 열기 전에**
알려 주는 검사를 넣어 뒀습니다. Node 만 있으면 됩니다(설치 불필요).

```bash
npm test          # 콘텐츠 계약 검사 — 무의존, 1초
```

잡아 주는 것: 철자 조각을 이어도 정답이 안 되는 경우 · 예문에 정답이 그대로 노출된 경우
(정보차가 깨짐) · `accept` 에 정답 누락 · 지문 `chunks` 가 빈칸을 빠뜨리거나 중복으로 덮는 경우
(그 빈칸은 게임에 영원히 안 나옵니다) · 단서가 4인분이 아닌 경우.

교실 투입 전에는 실제 브라우저로 완주까지 확인할 수 있습니다(선택 도구, Playwright 필요).

```bash
npm run serve                                  # 터미널 1
npm i -D @playwright/test && npx playwright install chromium
npm run test:e2e                               # 터미널 2 — 성 점령까지 자동 플레이
```

## 📱 플레이 방식 — 단일 기기 "패스앤플레이(핫시트)"

정식 4인 실시간 버전은 서버(Supabase/Firebase)가 필요하지만, 이 시제품은 **한 기기를
돌려 보며** 하는 방식으로 정보차 학습의 핵심을 그대로 살립니다.

1. 화면이 **"OO에게 기기를 넘겨주세요"** 라고 하면 그 사람에게 기기를 건넵니다.
2. 그 사람은 **자기 단서만 혼자** 확인합니다.
3. 화면을 숨기고, 팀원에게는 **말로만** 설명합니다.
4. 네 사람의 단서를 합쳐야 정답이 보입니다. **기록자(✍️)** 만 최종 답을 입력합니다.

## 🧭 게임 흐름

```
학교 입장 → 원정대 역할 배정 → binoculars 정보차 문제 → 🔭 망원경 획득
        → 안개 낀 성문 5개 정찰 → 자물쇠 적은 문 선택
        → 어휘 자물쇠 2개(obstacle · approach) 해제 → 성문 개방
        → ⚔️ 왕좌의 칼: 수능형 지문 6빈칸 협력 복원 → 👑 성 점령 + 순위표
```

### 4인 역할 (매 라운드 순환)
| 역할 | 담당 |
|---|---|
| 🔭 정찰자 (Scout) | 문·길 정보, 망원경 사용 |
| 📖 어휘 수호자 (Lexicon Keeper) | 뜻·정의 |
| ✍️ 기록자 (Scribe) | 첫 글자·글자 수, **최종 정답 입력** |
| 🎒 아이템 관리자 (Artifact Holder) | 철자 조각·어원·아이템 |

### 정보차 예시 (binoculars)
- 📖 어휘 수호자: 뜻 "멀리 있는 물체를 두 눈으로 확대해 보는 도구"
- ✍️ 기록자: 첫 글자 `b` · 글자 수 `10`
- 🔭 정찰자: 예문 "The guard used the ______ to watch the distant gate."
- 🎒 아이템 관리자: 철자 조각 `bin + ocular + s` (ocular = 눈과 관련된)

→ 네 단서를 합쳐 **binoculars** 완성 → 🔭 망원경 획득 → 안개 속 성문의 자물쇠 수 정찰!

### ⚔️ 왕좌의 칼 (클라이맥스)
수능형 지문 한 편(6빈칸: `obstacle · acquire · interpret · evidence · perspectives · significant`)을
네 역할이 **서로 다른 일부 정보**(핵심어휘 의미 / 중심 생각 / 어원 / 결론)만 보고 협력해 복원합니다.
